# Piotroski F-Score signals, machine learning and Indian mid- and small-cap returns

Status: research in progress. Main finding so far: on the available data the nine F-Score signals show no reliable power to rank next-12-month outperformers among Indian mid- and small-cap stocks, and XGBoost does no better than the plain F-Score. See docs/analysis_plan.md for the frozen analysis plan and the dated research log, and results/ for the tables.

## What this repository does
A reproducible pipeline that
1. builds the nine Piotroski signals from Yahoo Finance annual statements for Nifty Smallcap 250 and Nifty Midcap 150 companies (financial firms excluded, March year-end firms only);
2. computes each company-year's 12-month forward return, starting 3 months after fiscal year-end so that results are public, with no stale prices and no unfinished windows;
3. labels outperformance against the same-year median stock (robustness: equal-weighted mean, Nifty 50);
4. compares the plain F-Score, logistic regression, random forest and XGBoost out of sample, with company-level bootstrap intervals, permutation tests and a SHAP analysis.

## Data
Raw and processed data are not included because Yahoo Finance data cannot be redistributed. They are regenerated by the scripts below.

## Run (Python 3.11)
    python -m venv .venv311 && source .venv311/bin/activate
    pip install -r requirements.txt
    python tools/self_test.py                      # checks the code on synthetic data
    python src/fetch_universe.py <constituents.csv>   # NSE index list with a Symbol column; run once per list
    python src/fetch_extras.py                     # sectors and Nifty 50 history
    ./run_all.sh                                   # signals, returns, dataset, evaluation, SHAP, grouped CV

Settings are in src/config.py.

## Limitations
Only two fiscal years (FY2024, FY2025) have complete signals and a finished return window, so there is a single forward test year. Current index constituent lists are used (survivorship bias). Yahoo Finance data has limited depth and quality. No transaction costs are modelled. Earlier versions of this project contained a look-ahead bias and are not reproducible; they were discarded (see the research log).
